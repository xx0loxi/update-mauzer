# MAUZER

**MAUZER** — быстрый, тёмный, минималистичный браузер для Windows (включая Windows 7), собранный на Electron.

![MAUZER](MAUZER%20LOGO/main.png)

## Возможности

- 🔒 **Приватность**: встроенный блокировщик рекламы и трекеров (Pulse), защита от фингерпринта, Do Not Track, режим «Только HTTPS», поисковые подсказки и виджет погоды отключаются в настройках
- 🌑 **Инкогнито**: отдельные окна и вкладки без истории, куков и следов на диске
- ⚡ **Заморозка вкладок** (Frost Mode): неактивные вкладки выгружаются из памяти
- 📌 **Вкладки**: закрепление, mute, drag&drop, восстановление закрытых
- 🎨 **Тёмная тема**, акцентные цвета, тёплые темы новой вкладки (аврора + звёзды)
- 🌦 **Погода на новой вкладке** с анимированными иконками
- 📥 **Загрузки**: прогресс, панель загрузок, открытие в один клик
- 🔖 Закладки, история (SQLite), заметки, отложенное чтение, сессии
- 📦 **Импорт** закладок, истории и паролей из Chrome / Edge / Yandex / Brave
- 🔄 **Автообновление** через GitHub Releases

## Сборка из исходников

Требования: Node.js 16+, npm.

```bash
npm install
npm run build      # соберёт NSIS-инсталляторы (x64 + ia32) в dist/
npm start          # запуск в dev-режиме
```

## Структура проекта

```
main.js               — main-процесс Electron (окна, IPC, блокировщик, загрузки)
preload.js            — contextBridge API для рендереров
src/
  app.js              — UI браузера (вкладки, панель, настройки)
  index.html          — оболочка браузера
  newtab.html         — страница новой вкладки (погода, ссылки, фон)
  settings.html       — страница настроек
  incognito.html      — страница новой вкладки в инкогнито
  import.html         — мастер импорта данных
  main/               — модули main-процесса (utils, importer, history-db)
  lib/                — локальные библиотеки (QR-код)
scripts/              — вспомогательные скрипты (update-filters, benchmark)
```

## Windows 7

Ядро намеренно закреплено на **Electron 22** — последней версии, поддерживающей Windows 7. Не обновляйте Electron, если нужна совместимость с Win7.
