# Сборка урезанного ядра Electron 22.3.27 для Mauzer

## Что это

`args.gn` — конфиг, который выключает в ядре всё, что Mauzer не использует
(NaCl, DRM/Widevine, VR, геймпады, MIDI, орфография, окно печати Chrome,
отладочные символы, PGO/LTO). **Кодеки (YouTube) намеренно оставлены.**

Важно понимать: Electron — это уже «вырезанный Chrome» (без интерфейса,
вкладок, расширений, телеметрии). Этот слой урезания — последний; ожидаемый
эффект: −10–20% размера ядра, немного ОЗУ, скорость почти та же. Сборка же
сама становится в разы быстрее за счёт `symbol_level=0` и отказа от PGO/LTO.

## Где запускать

| Где | Время цикла | Комментарий |
|---|---|---|
| Ноут (6C/8GB, диск D:) | 8–14 ч | диск D: должен иметь 90+ ГБ; самый жирный этап пойдёт через своп — риск перезапуска |
| Арендный Windows-сервер 16 vCPU / 32 ГБ | 2–4 ч | ~$5–15 за весь цикл; результат — zip, скачиваешь и уничтожаешь сервер |

Требования (одинаково там и там): Git, Python 3.8+, Visual Studio 2022
BuildTools с «Разработка классических приложений на C++» + Windows SDK,
90+ ГБ на диске.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File scripts\core-build\build-core.ps1 -RootDir D:\mauzer-core
```

Скрипт: проверит окружение → скачает depot_tools и исходники → применит
`args.gn` → соберёт → положит результат в `D:\mauzer-core\result\*.zip`.

## Как вкрутить результат в Mauzer

1. Распаковать zip в `node_modules\electron\dist` (заменить содержимое).
2. `npm run build` как обычно — инсталлятор соберётся уже с твоим ядром.
3. Прогнать `npm run test:security` + скрытый бенчмарк (`MAUZER_HIDDEN_TEST=1 node benchmark.js --tabs=15`)
   и сравнить с базовыми цифрами.

## Не трогать в args.gn

- `proprietary_codecs = true` — иначе YouTube не играет;
- ничего из webview/IPC/session/webRequest — это основа Mauzer;
- `safeStorage` — хранение паролей.
